# ネオンランナー (NEON RUNNER)

スマホでも遊べる、シンセウェーブ世界観の単一HTMLファイル・エンドレスランナーゲームです。
ライブラリ不使用・外部依存なしで、`index.html` をブラウザで開くだけで動きます。

## 遊び方

- **タップ**(PCでは**クリック**または**スペースキー**)でジャンプ
- **長押し**すると少し高くジャンプ
- 右から流れてくるネオンの障害物をよけ続けて、走った距離のスコアを伸ばそう
- 障害物に当たるとゲームオーバー。タップでリトライ
- スコアが伸びると景色が **夕暮れ → 真夜中 → 夜明け** と移り変わっていく

効果音はWeb Audio APIで、グラフィックはすべてcanvas描画で生成しているため、画像・音声ファイルは一切不要です。

## ローカルで動かす

`index.html` をブラウザで直接開くか、簡易サーバーを起動します:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pagesで公開する(スマホ実機で遊ぶ)

1. GitHubのリポジトリページで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、ブランチ(例: `main`)と `/ (root)` を選択して保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開され、スマホのブラウザからアクセスして遊べます
