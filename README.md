# ネオンランナー (NEON RUNNER)

スマホでも遊べる、シンセウェーブ世界観の単一HTMLファイル・エンドレスランナーゲームです。
ライブラリ不使用・外部依存なしで、`index.html` をブラウザで開くだけで動きます。

## 遊び方

- **タップ**(PCでは**クリック**または**スペースキー**)でジャンプ、**長押し**で大ジャンプ
- 空中でもう一度タップすると**2段ジャンプ**(宙返り!)
- 障害物は3種類: **ネオン土管**と**スパイク**は跳び越え、**飛行ドローン**は跳ばずに下をくぐる
- **金色のコイン**は+10点。**8枚集めると FEVER** — 7秒間無敵になり、障害物を粉砕(+30点)、コイン2倍、スコア2倍!
- 障害物スレスレを通過すると**ニアミスボーナス +15点**
- 走るほどスピードが上がり、パターンも高難度に。景色は **夕暮れ → 真夜中 → 夜明け** と移り変わる
- ベストスコアは端末に保存。記録更新で **NEW RECORD!** 演出&リザルトから X(Twitter)にシェア可能
- 左上のボタン(PCでは**Mキー**)でサウンドON/OFF

効果音もBGM(シンセウェーブ風ループ)もWeb Audio APIでリアルタイム生成、グラフィックはすべてcanvas描画。画像・音声ファイルは一切不要です。

## ローカルで動かす

`index.html` をブラウザで直接開くか、簡易サーバーを起動します:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pagesで公開する(スマホ実機で遊ぶ)

1. GitHubのリポジトリページで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、ブランチ(例: `main`)と `/ (root)` を選択して保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開され、スマホのブラウザからアクセスして遊べます
